# ChopShop — Website (Demo)

Demo website for **ChopShop**, The Gambia's fast-food chain — famous for its sweet-bun burgers, grilled chicken and shawarma, trading since 2014.

## What's here

- `index.html` — the complete single-page website in one self-contained file (Google Fonts is the only external resource):
  - **Hero — "The burger builds itself":** a scroll-driven sequence where a hand-drawn SVG burger first pulls apart layer by layer, then drops back into the stack one layer at a time (bottom bun, sauce, patty, cheese, onion, tomato, lettuce, top bun), and finally sinks into a takeaway box whose lid closes. Vanilla JS + `requestAnimationFrame` on scroll; no libraries. Without JS — or with reduced-motion settings — the assembled burger and call-to-action simply show as a static hero.
  - **Build Your Own:** an interactive stacker — toggle extras (extra patty, beef strips, cheese, egg, lettuce & tomato, grilled onions, extra sauce) and watch the SVG stack, layer count and dalasi total update live.
  - **Menu:** card-grid menu in seven categories (Burgers, Combos & Buckets, Grilled Chicken, Fish & Seafood, Shawarma & Wraps, Sides, Shakes & Juices) with sample dalasi prices.
  - **Find Us:** both branches, opening hours, phone, and the Google rating line.
- `space.json` / `AGENTS.md` — original build metadata and notes.

## Status

Concept demo. Menu items and prices are sample estimates in the ranges the business is known to charge, to be replaced with ChopShop's real menu card before the site is promoted as final. The only order channel shown is the published phone number — ChopShop publishes no WhatsApp number or email, so none is shown.
